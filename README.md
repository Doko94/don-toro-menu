# Carta Digital Don Toro - Netlify

## Cómo subir a Netlify

1. Entra a https://app.netlify.com/
2. Arrastra la carpeta completa `carta_don_toro_netlify` o el ZIP descomprimido.
3. Netlify generará una URL pública.
4. Crea un código QR apuntando a esa URL.

## Archivos principales

- `index.html`: contenido de la carta.
- `style.css`: colores, fondo, tipografías y diseño responsive.
- `script.js`: marca activa la categoría visible.

## Personalización rápida

Busca en `style.css`:

```css
--bg:#1f2327;
--card:#252a2f;
--text:#f7f4ee;
--gold:#b58a3a;
```

Ahí puedes ajustar los colores para que queden igual al diseño final del restaurante.
